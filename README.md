# 쉬운 작곡 프로그램

한국어로 쉽게 쓰는 작곡 프로그램이에요. 칸을 클릭해서 음을 찍고, 재생 버튼으로 바로 들어볼 수 있어요.

## 기능

- 칸 클릭으로 음 찍기 (찍는 순간 소리 미리듣기)
- 왼쪽 음 이름(도, 레, 미...)을 누르면 그 음 듣기
- 재생, 정지, 반복, 빠르기 조절
- 모두 지우기
- 곡 저장, 불러오기 (`.json` 파일)
- 모든 메뉴가 한글

## 실행 방법

1. 파이썬을 설치해요. (3.9 이상 권장)
2. 필요한 라이브러리를 설치해요.

   ```
   pip install -r requirements.txt
   ```

3. 프로그램을 실행해요.

   ```
   python composer.py
   ```

## 알아둘 점

- 소리는 사인파로 만든 단순한 소리예요. 악기 소리는 나중에 추가할 예정이에요.
- 첫 버전이라 부족한 부분이 있어요.
